# City Guide

City Guide is a stylish, responsive city discovery website for people looking for curated places to eat, art venues, and local recommendations in a clean editorial layout. The experience is designed to feel modern, minimal, and easy to browse on desktop and mobile.

## Live Demo

Visit the live site here: [city-guide-up.netlify.app](https://city-guide-up.netlify.app)

## Overview

This project is a lightweight static web experience built with HTML, CSS, and simple client-side navigation. It presents a focused city guide interface with dedicated views for food and art, making it a good fit for users searching for:

- city guide website
- local food recommendations
- restaurant discovery
- art and culture listings
- curated urban travel guide
- responsive static website
- Netlify hosted site

## Features

- Clean, professional UI with a premium editorial feel
- Separate sections for dining and arts/culture content
- Responsive layout optimized for mobile and desktop
- Fast loading static pages with no framework overhead
- Netlify-ready deployment
- SEO-friendly project keywords for city guide, food guide, and art guide searches

## Project Structure

- `index.html` - landing entry point that redirects to the main experience
- `eat.html` - food and restaurant discovery page
- `art.html` - art, gallery, and culture discovery page

## How It Works

The root page redirects visitors to the food-focused experience, while the other pages provide curated city content with a consistent visual style and navigation.

## Deployment
